      Under the hood

      Old Google — PageRank

      Every page starts equal. Each round, a page shares its score equally among the pages it links to. A link from a high-scoring page passes on more than one from a low-scoring page. We repeat (damping 0.85) until scores stop changing.

      New Google — Link Popularity

      Count how many different sites link to a page. The most incoming links ranks first. It ignores who is linking: a link from any site counts as one.

      Size nodes byHover or focus a node to see who links to it. Glowing nodes match your search.
